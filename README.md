# Claude Code Skills & Plugins — sample repository

Companion files for the book *Claude Code Skills & Plugins* by Toru Hayase.

- `invoice-api/` — the small TypeScript API you work in throughout the book
- `patches/` — changes you apply during the book, such as the branch you review in Chapter 3

## How this repository is organized

- The `main` branch is the starting point. Clone it and follow the book from Chapter 1.
- Each chapter's end state is tagged: `ch01`, `ch02`, and so on. Run `git diff ch03` to compare your work with the end of Chapter 3.
- The `solutions` branch holds the finished state of the last chapter.
