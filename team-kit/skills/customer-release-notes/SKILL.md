---
description: Writes customer-facing release notes from the newest
  version in CHANGELOG.md. Use when the user asks for release notes,
  a release announcement, or what to tell customers about a version.
when_to_use: For example "announce 1.2.0 to our customers", "what's new
  for users in this version?", or "prepare the release write-up".
---

Write release notes for customers from the newest version in
`CHANGELOG.md`.

1. Write for customers, not developers. No file names, no function
   names.
2. Group the changes under "New", "Improved", and "Fixed": Added
   becomes New, Changed becomes Improved, and Fixed stays Fixed.
   Leave out a group that has no changes.
3. Keep it under 120 words. Use plain American English.
4. End with: "Questions? Contact support@example.com."
